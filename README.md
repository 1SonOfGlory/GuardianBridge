# GuardianBridge scaffold

A Laravel and React application scaffold with account, profile, password, and two-factor-authentication pages. This snapshot is primarily framework setup. It does not establish an implemented GuardianBridge product or a trained model.

Install PHP dependencies with `composer install` and JavaScript dependencies with `npm ci`. Configure your own Laravel environment, generate an application key, and apply the migrations before running the development servers. No environment file, application key, database, or uploaded records is included.

The generated framework components retain their original structure. Product-specific behavior and end-to-end deployment remain to be implemented and verified. This repository is included for source completeness, not as a finished portfolio project.
